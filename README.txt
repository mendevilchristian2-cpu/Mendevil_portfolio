CHRISTIAN LL. MENDEVIL — PROFESSIONAL IT PORTFOLIO

DESIGN DIRECTION
A distinct technical/editorial interface using midnight charcoal, deep navy panels, steel blue, and restrained cyan accents. This design intentionally differs from the pastel portfolio style used for other classmates.

FILES
- index.html: portfolio structure and content
- style.css: responsive visual design
- script.js: mobile navigation, project filters, project detail dialog, active section navigation, reading progress, copy-email, and back-to-top controls
- christian-profile.png: supplied profile photograph
- project-inventory.png, project-pwd.png, project-transport.png: illustrative project dashboard visuals

HOW TO OPEN
1. Extract the ZIP file.
2. Keep all files in the same folder.
3. Open index.html in a modern browser.

NOTES
Project dashboard visuals are illustrative mockups created for portfolio presentation and do not represent verified screenshots of deployed applications. Sample figures shown in the mockups are illustrative. No unprovided certifications or project repository links have been invented.

For publishing, upload the extracted files to a GitHub repository and enable GitHub Pages from the repository's Settings > Pages.
